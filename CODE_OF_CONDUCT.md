# Code of conduct

Be kind and be useful. We follow the spirit of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
no harassment, no personal attacks, respect for different experience and
opinions. Report problems through a private GitHub security advisory or by
contacting the maintainer through their GitHub profile. Maintainers may
remove comments and contributions that break these rules.

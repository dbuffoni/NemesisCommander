# 0046. Release 0.2.0: shell exit, terminal, folder text, MCP, plugin columns

- Status: Accepted
- Date: 2026-11-22

## Context

Eleven cards carry release 0.2.0: SC-2 (cd on exit), SC-36 (terminal
launcher), SC-57 (folder text), SC-105 (quick view of archives), SC-30
(plugin columns and previewers), SC-56 (MCP server), and the five cards
SC-126..130 (copiable log, lingering with sudo, TUI visual issues, install on
localhost, bottom bar with Shift/Ctrl).

## Decision

- **cd on exit (SC-2).** `nmc --cwd-file FILE` writes the folder of the active
  panel to FILE when the interface ends; `nmc shell-init bash|zsh|fish|pwsh`
  prints a shell function `nmc` that passes the file and changes to the folder.
  Subcommands and options bypass the function. A panel on a server leaves the
  shell where it was (nothing to `cd` to).
- **Terminal launcher (SC-36).** Command `files.open-terminal`, setting
  `general.terminal` (`{dir}`, `{cmd}`). Window: starts the terminal detached
  (`terminal.rs` builds the command lines per platform; pure functions, tested
  for each). Terminal UI: it ends like SC-2 (needs the shell function, else an
  explanation). Servers reached with SSH (`sftp`, `agent`): `ssh -t host 'cd DIR
  && exec $SHELL -l'`, in the terminal UI as an external program and in the
  window in a terminal window.
- **Folder text (SC-57).** `nmc_folder.md` (and `sc_folder.md`, the name on the
  card) is rendered at the top of the panel, at most a third of its height, up
  to 64 KiB. Terminal UI only for now: the window's model has no row for it.
- **Archives (SC-105).** F3 and the quick view show the contents of an archive
  (size, date, name; at most 5000 rows) instead of the description of the bytes.
  Encrypted or damaged archives fall back to the old view.
- **Plugin columns and previewers (SC-30).** The manifest may declare
  `columns` and `previewers` with `match` masks. They run the script as the
  command `column:ID` (selection = the matching files, one printed line per
  file) and `preview:ID` (prints Markdown). They run only for plugins the user
  already allowed: nothing starts by itself before that. A plugin may have only
  columns and previewers (no command). Shown in the terminal UI (columns before
  the size) and in the viewers; the window shows previewers but not yet columns.
- **MCP server (SC-56).** `nmc mcp` (feature `mcp`, crate `nmc-mcp`): JSON-RPC
  over stdio, written on `serde_json` (no SDK). Tools: list, stat, read (1 MiB,
  secret names refused), search, hash, mkdir, copy, move, rename, trash. Nothing
  is allowed by default; `--read`, `--write`, `--grants FILE`. Every path is
  checked after `..` and, for local paths, after symbolic links, and every
  step of a copy plan is checked again. Mutating tools take `dry_run`; copy
  never overwrites unless asked; deleting only trashes. `--log FILE` records
  the calls. Not done: pack/unpack tools, the transfer journal (SC-18) for undo,
  archives in `search`.
- **Lingering (SC-127).** When the install finds lingering off, the failure
  window offers to turn it on with the sudo password of the server: asked
  masked, written to a mode 600 file fed to `sudo -S`, deleted at once, never
  logged or saved; the install then runs again to verify.
- **Localhost (SC-129).** A target that is this computer (localhost, loopback,
  no other user, no port) runs its install scripts with `sh -c`: no SSH server
  is needed.
- **Bottom bar (SC-130).** The terminal UI switches on the keyboard protocol
  (kitty flags: release events, modifier keys on their own, shifted
  characters) when the terminal supports it, so the function key bar follows
  Shift and Ctrl. Other terminals keep the plain keys; a terminal that never
  reports a bare Shift press cannot be helped.
- **Copiable log (SC-126).** `c` in a log window copies its lines; the hint says so.

## Consequences

- The Qt window could not be built in the cloud: its Rust and QML were not
  touched. It gets previewers, archive contents and the log copy (all in the
  shared model); folder text and plugin columns need a row in its model next.
- `nmc mcp` adds a crate and about a thousand lines; agent-only builds leave
  it out with the `mcp` feature.
